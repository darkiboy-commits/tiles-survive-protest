Что произошло? What happened?

FunPlus в лице разработчиков Tiles Survive убрали коробки с ускорителями для игроков, которые присоединяются к рейдам. Раньше все участники получали награды за помощь союзникам. Теперь только организатор рейда получает нормальные коробки. Присоединившиеся игроки почти ничего не получают.

FunPlus in the face of Tiles Survive developers removed speed-up boxes for players who join raids. Before, all participants got rewards for helping allies. Now only the raid organizer gets decent boxes. Joining players get almost nothing.

Это изменение убило мотивацию помогать. Зачем участвовать в рейде союзника, если нет награды? Командная игра разрушена.

This change killed the motivation to help. Why join an ally's raid if there's no reward? Teamwork is destroyed.

Мы требуем вернуть прежнюю систему наград для всех участников рейдов.

We demand the return of the previous reward system for all raid participants.
